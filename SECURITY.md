# Security

Please report a security problem in this plugin or in Hazelchat to hello@hazelchat.co, with "Security" in the subject. We answer within one business day and fix confirmed problems in a new release.

The plugin prints one script tag with your public widget key, which is not a password. The script address is fixed in the code and cannot be changed in the settings. The plugin makes no requests from October, stores only the key and one switch in October's settings table, and only administrators with its permission can change them.
